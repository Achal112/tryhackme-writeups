# Task 2: Month 1 – Common Computer Types

Sophia learned about four major computer types.

---

## 🔹 Laptop

* Portable
* Battery powered
* Used for daily tasks

---

## 🔹 Desktop

* Fixed at one location
* Better cooling
* Better long-term performance

---

## 🔹 Workstation

* Built for professional work
* High precision and reliability
* Used for:

  * Simulations
  * 3D design
  * Engineering tasks

---

## 🔹 Server

* No monitor or keyboard required
* Runs continuously
* Provides services to many users

---

### Comparison Table

| Computer Type | Main Purpose                |
| ------------- | --------------------------- |
| Laptop        | Portable everyday use       |
| Desktop       | Strong fixed performance    |
| Workstation   | Professional precision work |
| Server        | Network services            |

---

### ✅ Answers:

* No screen/keyboard → `server`
* Precision work → `workstation`

# Task 3: Month 2 – Hidden Computers

Sophia discovered computers hidden in daily life.

---

## 🔹 Smartphone

* Pocket-sized computer
* Optimized for battery and internet

Examples:

* Android
* iPhone

---

## 🔹 Tablet

* Larger touch-screen device

Examples:

* iPad
* Drawing tablets

---

## 🔹 IoT Device

Internet-connected devices with one purpose.

Examples:

* Smart thermostat
* Smart doorbell
* Fitness tracker

---

## 🔹 Embedded Computer

Tiny computer built inside another device.

Examples:

* Coffee machine controller
* Automatic doors
* Sensors

---

### 🔹 Important Difference

| Type              | Connectivity                  |
| ----------------- | ----------------------------- |
| IoT Device        | Connected to internet/network |
| Embedded Computer | May not connect to internet   |

---

### ✅ Answers:

* Pocket computer → `smartphone`
* Coffee machine computer → `embedded computer`
